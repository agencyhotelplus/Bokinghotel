## Cara pasang
1. Upload/replace 4 file ke repository GitHub pada branch `main`.
2. Pastikan nama file persis sama.
3. Aktifkan Settings → Pages → Deploy from branch → `main` / root.
4. Buka URL GitHub Pages.

## Catatan penting
